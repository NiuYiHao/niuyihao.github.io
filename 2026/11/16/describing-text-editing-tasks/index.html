如何准确描述文本修改任务

2026-11-16 · 5 min · 1.7k words · 阅读量：加载中… 次

使用 AI 修改文本时，可以通过明确操作类型和约束条件，提高结果的准确性。

1. 基于共同键的交集更新

定义：以 A 为基准，对 A、B 共有的项目取内容交集，其余保留不变。

功能：整合两份资料中的共同信息。

用例：

Input

原始资料 A：

物品 菌种
手机屏幕 表皮葡萄球菌、金黄色葡萄球菌
鼠标、键盘 表皮葡萄球菌、金黄色葡萄球菌

参考资料 B：

物品 菌种
手机 大肠杆菌、金黄色葡萄球菌

Instruction

任务指令：

以 A 为基准，将“手机屏幕”和“手机”视为同一物品。双方共有的物品，其菌种取交集；仅 A 中存在的物品及其菌种保持原样。

Output

修改结果：

物品 菌种
手机屏幕 金黄色葡萄球菌
鼠标、键盘 表皮葡萄球菌、金黄色葡萄球菌

这里完成的是两份文本的交集运算，菌种与物品的实际对应关系仍需检测资料支持。

2. 基于参考资料的答案修订

定义：根据参考资料修改已有答案。

功能：更新、纠正或补充现有内容。

用例：

Input

参考资料 A： “常见物品上的细菌”表，列出物品及对应菌种。

问题 B： 风险有多大？

已有答案：

对皮肤状态有直接影响：风险主要集中在局部皮肤问题（如长痘、闭口、皮肤发痒）和心理舒适度上。尤其是如果伴侣本身是油性皮肤、痘痘肌或敏感肌，反应会更明显。

Instruction

任务指令：

基于参考资料 A，对问题 B 的现有解答进行修订。

Output

修订结果要点：

A 提供了菌种名称。评估具体接触的风险，还需要细菌数量、转移程度、接触部位及皮肤屏障状态等信息。

3. 基于参考资料的独立答案生成

定义：仅依据参考资料和问题，独立生成答案。

功能：使重新作答聚焦于参考资料和当前问题。

用例：

Input

参考资料 A： 沿用“常见物品上的细菌”表。

问题 B： 风险有多大？

Instruction

任务指令：

仅依据参考资料 A 和问题 B，独立生成答案。

Output

生成结果要点：

A 能够提供菌种线索。回答“一次摸脸的风险有多大”，需要进一步获得实际暴露情况和相应的发病数据。

本例中，参考资料和问题构成作答输入，已有答案退出输入范围。

4. 问题重构与独立答案生成

定义：先修改原问题，再针对新问题生成答案。

功能：调整问题的范围、重点或表达方式。

用例：

Input

原问题 B： 风险有多大？

新问题 C： 有何风险？

Instruction

任务指令：

将问题改为“有何风险”，基于 A 独立生成答案。

Output

生成结果节选：

细菌 可能的风险
金黄色葡萄球菌 皮肤及软组织感染，表现为红肿、疼痛、化脓。
大肠杆菌 肠道致病型经口摄入后，可引起腹泻、腹痛。

问题由“风险大小”调整为“风险类型”，回答相应转向列举可能发生的健康问题。

5. 客观化改写与去主观化

定义：保留核心信息，删减主观评价、对他人心理的推测及个人化叙述，将表达调整为具体行为、事实和条件。

功能：减少情绪化措辞及对他人反应的预设，使内容适用于更广泛的情境。

用例：

Input

原文：

  • 摸脸前先洗手：这是最直接有效的方法。刚骑完车、吃完东西或用完电脑后，去洗个手再抱抱她、摸摸她的脸，她不仅不会排斥，还会觉得你很贴心、很尊重她的感受。
  • 调整亲昵的部位：如果当时手边不方便洗手（比如刚停好摩托车或正在看手机），可以把摸脸换成搂肩膀、牵手腕、摸摸头发或轻轻拥抱。这些部位的皮肤耐受度高，不会引起她的卫生焦虑。
  • 定期清洁高频物品：平时顺手用酒精湿巾擦一擦手机屏幕、鼠标键盘和摩托车把手，既能减少细菌滋生，也能让她看到你为她做出的努力。

Instruction

任务指令：

客观化改写（Objective Rewriting），去主观化（Depersonalization）。

Output

修改结果：

  • 触摸面部前清洁双手：接触车把、手机、键盘或食物后，可用肥皂和流动水洗手，减少手部污物和微生物的转移。
  • 协商身体接触方式：根据双方意愿选择拥抱、搂肩等接触方式，尊重对方对接触部位和卫生的要求。
  • 定期清洁高频接触物品：按照产品清洁说明，选择适用的清洁用品处理手机、鼠标键盘和车把；使用酒精类产品前，确认材质兼容性。

6. 基于结构类比的交叉补全

定义：利用不同条目中已有的内容作为参考，按照共同的结构和表达方式，补全各条目的缺失部分。

功能：保持各条目在内容结构、表述风格和详细程度上的一致性。

7. 基于对话检索和结构类比的交叉补全

定义：基于已有条目的结构进行类比，从指定对话中检索相关内容，交叉补全缺失信息。

功能：补全不完整的内容，保持结构与风格一致，并确保内容有据可查。

用例：

Input

撰写《如何准确描述文本修改任务》时，第1—4节已有“定义”和“功能”，第5节已有“用例”。

Instruction

参考第1—4节的结构补全第5节的定义与功能；从当前对话检索真实案例，参照第5节的格式补全第1—4节的用例。

Output
